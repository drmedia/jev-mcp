# Claude Code Additional Instructions

`AGENTS.md` is the primary shared development instruction file for this repository.

Follow it before making any change.

For substantial changes:

- inspect the current implementation first,
- use planning before changing architecture,
- prefer focused edits over broad rewrites,
- run the required tests after implementation.

When developing or debugging MCP functionality, use Claude Code's MCP tooling where useful.

Do not create Claude-specific architecture that diverges from the shared project architecture defined in `AGENTS.md`.
